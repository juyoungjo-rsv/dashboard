# 우리 둘의 비밀일기 📓🔒

여동생과 단둘이 쓰는 교환일기 모바일 대시보드입니다. Next.js(App Router) + SQLite 기반의
작은 풀스택 앱으로, 두 계정만 로그인할 수 있는 비공개 서비스로 동작합니다.

## 주요 기능

- **교환일기**: 서로의 일기를 한 피드에서 볼 수 있고, 날짜별로 하루 한 편씩 작성합니다.
- **댓글**: 상대방 일기에 댓글을 남길 수 있어요.
- **캐릭터 꾸미기**: 몸 색깔 / 표정 / 모자 / 악세서리 / 옷을 포인트로 잠금해제하고 착용합니다.
- **포인트 지급**
  - 일기 작성 1회당 **+10P** (하루 한 번)
  - 댓글 작성 시 **+5P** (하루 최대 3개까지 지급, 그 이상은 댓글만 남고 포인트는 없음)
  - **5일 연속 작성** 시마다 **+30P** 보너스
- **이미지 업로드**: 일기 작성 시 사진을 최대 4장까지 첨부할 수 있어요.
- **데이터 보존**: 일기·댓글·이미지·포인트 내역은 모두 SQLite DB(`data/dashboard.db`)와
  로컬 파일(`data/uploads/`)에 저장되어 새로고침하거나 서버를 재시작해도 사라지지 않습니다.

## 시작하기

### 1. 의존성 설치

```bash
npm install
```

### 2. 환경변수 설정

`.env.example`을 복사해서 `.env.local`을 만들고 값을 채워주세요.

```bash
cp .env.example .env.local
```

- `SESSION_SECRET`: 로그인 세션 서명용 비밀 키. `openssl rand -hex 32`로 생성하세요.
- `USER1_*` / `USER2_*`: 언니·동생 두 계정의 아이디/비밀번호/닉네임. **최초 실행 시 한 번만**
  DB에 계정이 생성되므로, 반드시 배포 전에 원하는 값으로 미리 설정해두세요.

### 3. 개발 서버 실행

```bash
npm run dev
```

브라우저(또는 모바일)에서 `http://localhost:3000` 접속 후 `.env.local`에 설정한 계정으로
로그인하면 됩니다.

### 4. 배포 시 주의사항

- `data/` 디렉터리(SQLite DB + 업로드 이미지)는 컨테이너/서버가 재시작돼도 유지되도록
  **영구 볼륨**에 마운트해야 합니다. 이 폴더가 사라지면 일기와 사진도 함께 사라집니다.
- HTTPS 환경에서 배포하면 세션 쿠키가 자동으로 `Secure` 옵션으로 발급됩니다.

## 기술 스택

- **Next.js 14 (App Router)** — 페이지 + API 라우트를 한 프로젝트에서 처리
- **node:sqlite** — Node.js 내장 SQLite (별도 네이티브 빌드 없이 파일 기반 영구 저장)
- **bcryptjs** — 비밀번호 해싱
- **Web Crypto(HMAC) 서명 쿠키** — 별도 인증 라이브러리 없이 자체 세션 구현

## 폴더 구조

```
app/
  login/              로그인 페이지
  (app)/              로그인 후 화면 (하단 탭 공통 레이아웃)
    dashboard/         홈 — 캐릭터, 포인트, 연속 작성 현황
    diary/             교환일기 피드 + 작성
    diary/[id]/        일기 상세 + 댓글
    character/         캐릭터 꾸미기(포인트 상점)
  api/                 REST API 라우트 (인증, 일기, 댓글, 캐릭터, 포인트, 업로드)
lib/                  DB 스키마, 세션, 인증, 포인트/스트릭 로직, 캐릭터 아이템 정의
components/           공통 UI 컴포넌트 (헤더, 하단 탭, 아바타, 토스트)
data/                 (git 제외) SQLite DB + 업로드 이미지 저장 위치
```
