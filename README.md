# 우리 둘의 비밀일기 📓🔒

여동생과 단둘이 쓰는 교환일기 모바일 대시보드입니다. 아래 순서대로 따라 하면
링크 하나로 두 분이 폰에서 접속해서 쓸 수 있는 상태가 됩니다. **전부 무료**이고,
신용카드도 필요 없어요.

---

## 🚀 인터넷에 올리기 (처음 한 번만 하면 돼요)

전체 흐름은 이래요:

1. **Vercel**(무료) 가입 → 이 GitHub 저장소 연결 → "배포" 버튼 클릭
2. **Turso**(무료) 가입 → 데이터베이스 하나 생성 → 주소·비밀키 복사
3. 그 값들을 Vercel에 붙여넣기 → 사진 저장 기능 켜기 → 재배포
4. 완성된 주소를 동생과 나눠 가지기

하나씩 자세히 볼게요.

### 1단계. Vercel에 가입하고 이 저장소를 연결하기

1. [vercel.com](https://vercel.com) 접속 → **"Sign Up"** 클릭 → **"Continue with GitHub"** 선택
   (GitHub 계정으로 로그인, 별도 비밀번호 안 만들어도 돼요)
2. 로그인 후 **"Add New..." → "Project"** 클릭
3. `juyoungjo-rsv/dashboard` 저장소를 찾아서 **"Import"** 클릭
4. 브랜치 선택 화면이 나오면 `claude/exchange-diary-mobile-dashboard-c439gc` (또는 이 내용을
   합쳐둔 `main`)를 선택해주세요.
5. 아직 **"Deploy" 버튼을 누르지 마세요.** 그 위에 있는 **"Environment Variables"**
   부분을 펼쳐서 아래 값들을 먼저 입력해주세요 (한 줄에 하나씩, 이름=값 형태로 추가):

   | 이름 | 값 |
   |---|---|
   | `SESSION_SECRET` | 아무 긴 문자열 (예: `sdf82hf9283hfsdkjf982h3f`처럼 막 입력해도 됨) |
   | `USER1_USERNAME` | 언니가 쓸 아이디 (예: `unni`) |
   | `USER1_PASSWORD` | 언니가 쓸 비밀번호 |
   | `USER1_DISPLAY_NAME` | 언니 화면에 보일 이름 (예: `언니`) |
   | `USER2_USERNAME` | 동생이 쓸 아이디 (예: `dongsaeng`) |
   | `USER2_PASSWORD` | 동생이 쓸 비밀번호 |
   | `USER2_DISPLAY_NAME` | 동생 화면에 보일 이름 (예: `동생`) |

   > ⚠️ 이 아이디/비밀번호는 **맨 처음 딱 한 번**만 계정 생성에 쓰여요. 나중에 값을
   > 바꿔도 이미 만들어진 계정에는 반영되지 않으니, 신중하게 정해주세요.

6. 아직 데이터베이스 관련 값(`TURSO_...`)은 안 넣어도 괜찮아요 — 2단계에서 채웁니다.
7. **"Deploy"** 클릭! 1~2분 기다리면 `https://무언가.vercel.app` 주소가 생겨요.
   (이 시점엔 로그인해도 일기가 저장 안 될 수 있어요 — 2단계까지 마쳐야 완성돼요)

### 2단계. Turso에 가입하고 데이터베이스 만들기

일기·댓글·포인트 데이터를 저장할 공간이에요. (사진은 3단계의 Vercel Blob에 저장돼요)

1. [turso.tech](https://turso.tech) 접속 → 가입(GitHub 계정으로 로그인 가능)
2. 로그인 후 대시보드에서 **"Create Database"**(또는 비슷한 이름의 버튼) 클릭
3. 이름은 아무거나 (예: `sister-diary`) 입력하고 생성
4. 생성된 데이터베이스 페이지에서:
   - **연결 주소(Database URL)**: `libsql://...` 형태의 값
   - **인증 토큰(Auth Token)**: "Create Token" 같은 버튼을 눌러서 발급받는 긴 문자열
   
   이 두 값을 복사해두세요.

   > 화면 구성이 살짝 다르게 보이거나 결제 정보를 요구하는 화면이 나오면, 무료 플랜인지
   > 꼭 확인해주세요. 헷갈리면 캡처해서 알려주시면 같이 확인해드릴게요.

### 3단계. Vercel에 값 채우고 사진 저장 기능 켜기

1. Vercel 프로젝트 페이지 → **"Settings" → "Environment Variables"**로 이동
2. 방금 복사한 두 값을 추가:
   - `TURSO_DATABASE_URL` = (복사한 연결 주소)
   - `TURSO_AUTH_TOKEN` = (복사한 인증 토큰)
3. 같은 프로젝트의 **"Storage"** 탭으로 이동 → **"Create Database"**(또는 "Browse Marketplace")
   → **"Blob"** 선택 → 무료 플랜으로 생성 → 프로젝트에 연결
   (이렇게 하면 `BLOB_READ_WRITE_TOKEN`이라는 값이 자동으로 채워져요. 직접 입력할 필요 없어요)
4. **"Deployments"** 탭으로 가서 가장 최근 배포 옆 **"..." 메뉴 → "Redeploy"** 클릭
   (환경변수를 바꾼 뒤에는 항상 재배포를 한 번 해줘야 반영돼요)

### 4단계. 동생과 함께 쓰기

배포가 끝나면 나오는 주소(`https://프로젝트이름.vercel.app`)를 동생에게 카톡 등으로
보내주세요. 둘 다 폰 브라우저에서 그 주소로 접속해서, 각자의 아이디/비밀번호로
로그인하면 끝이에요. (아이폰이면 공유 버튼 → "홈 화면에 추가", 안드로이드면 브라우저
메뉴 → "홈 화면에 추가"를 하면 앱처럼 아이콘을 눌러 바로 들어갈 수 있어요)

## 이 앱이 하는 일

- **교환일기**: 둘이 같은 화면에서 서로의 일기를 보고, 하루 한 편씩 씁니다.
- **댓글**: 상대 일기에 댓글을 남길 수 있어요.
- **포인트**: 일기 작성 +10P, 댓글 작성 +5P(하루 3개까지만), 5일 연속 작성 +30P 보너스.
- **캐릭터 꾸미기**: 모은 포인트로 몸 색깔·표정·모자·악세서리·옷을 잠금해제하고 착용.
- **사진 첨부**: 일기에 사진을 최대 4장까지 붙일 수 있어요.
- **데이터 보존**: 일기·댓글·사진·포인트는 전부 Turso(데이터베이스)와 Vercel Blob(사진
  저장소)에 저장돼서, 새로고침은 물론 재배포를 해도 사라지지 않아요.

## 로컬 컴퓨터에서 미리 확인해보고 싶다면

Turso/Vercel 계정 없이도 내 컴퓨터에서 먼저 테스트해볼 수 있어요.

```bash
npm install
cp .env.example .env.local   # SESSION_SECRET, USER1_*, USER2_*만 채우면 됨
npm run dev
```

`http://localhost:3000` 접속 후 로그인하면 됩니다. 이 모드에서는 데이터가 내 컴퓨터의
`data/` 폴더에 저장되고(git에는 올라가지 않음), 사진 업로드는 Blob 설정 전까지는 동작하지
않아요(안내 메시지가 떠요).

## 기술적으로 어떻게 되어있나 (참고용)

- **Next.js 14 (App Router)** — 화면과 서버 API를 한 프로젝트에서 처리
- **Turso (libSQL)** — SQLite 호환 데이터베이스, 서버가 재시작돼도 데이터 유지
- **Vercel Blob** — 업로드한 사진 저장소
- **bcryptjs** — 비밀번호 해싱
- **Web Crypto(HMAC) 서명 쿠키** — 별도 인증 라이브러리 없이 자체 세션 구현

```
app/
  login/              로그인 페이지
  (app)/              로그인 후 화면 (하단 탭 공통 레이아웃)
    dashboard/         홈 — 캐릭터, 포인트, 연속 작성 현황
    diary/             교환일기 피드 + 작성
    diary/[id]/        일기 상세 + 댓글
    character/         캐릭터 꾸미기(포인트 상점)
  api/                 REST API 라우트 (인증, 일기, 댓글, 캐릭터, 포인트)
lib/                  DB 스키마, 세션, 인증, 포인트/스트릭 로직, 캐릭터 아이템 정의, 업로드
components/           공통 UI 컴포넌트 (헤더, 하단 탭, 아바타, 토스트)
```
