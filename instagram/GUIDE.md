# 스위트스팟 인스타그램 포트폴리오 콘텐츠 작성 가이드

- 계정: @sweetspot_official (브랜드를 위한 오프라인 경험 제작사)
- 콘텐츠 유형: 포트폴리오 전환형 카드뉴스 (팝업·오프라인 캠페인 사례 분석)
- 목표: 브랜드 담당자가 사례를 읽고 "우리 브랜드도 이런 경험 설계가 필요하다"고 느껴 포트폴리오 확인·문의로 이어지게 하는 것
- 기준 자료: 성과가 좋았던 콘텐츠 7개 (`EXAMPLES.md`). 성과 수치는 받지 못했으므로 이 가이드는 글의 반복 공식을 정리한 것이다.

---

## 0. 작성 요청을 받으면

### 먼저 확인할 정보 (없는 항목은 비워두고 진행, 모르는 사실은 지어내지 않는다)

| 항목 | 예시 |
|---|---|
| 브랜드 / 제품 | 필립스 / 바리스티나 커피머신 |
| 시기·장소 | 2025년 9월, 성수 |
| 팝업 목적·과제 | MZ에게 신제품을 지루하지 않게 소개 |
| 핵심 장치 1개 | 고객이 직접 커피를 내리는 체험 |
| 기타 구성 | 포토존, 이벤트존 등 |
| 스위트스팟의 역할 | 기획 / 공간 제작 / 운영 등 |
| 현장 디테일·비하인드 | 스태프 배치, 동선 설계 등 |
| 성과 | 방문객 수, 대기, 판매, SNS 인증 등 |

### 결과물 형식

1. 1장 제목 후보 3개 (유형별로 다르게) + 추천 1개
2. 2장~마지막 장 본문 (장 번호 표기, 장당 3~5문장, 약 150~250자)
3. 캡션 (아래 캡션 공식 그대로)
4. 확인이 필요한 사실 목록 (날짜·명칭·수치 등 추측한 부분)

## 1. 1장 제목 (훅)

2줄 구성. 첫 줄이 긴장을 만들고 둘째 줄이 대상을 밝힌다. **답은 1장에 절대 넣지 않는다.** 가능하면 브랜드명을 넣는다(7개 중 6개).

| 유형 | 예시 | 원리 |
|---|---|---|
| 역설 + 이유 | 룰루레몬은 왜 잠실에 / 사우나를 열었나 | 브랜드와 어울리지 않는 행동, 이유는 숨김 |
| | 가구 브랜드가 / 제품 대신 '방'을 판 이유 | 업종 상식을 뒤집음 |
| | 고객을 번거롭게 만든 / 필립스의 숨은 전략 | 부정어가 긍정적 전략으로 |
| 대비 | 같은 장소, 같은 컨셉인데 / 결과는 달랐다 | 같은 조건, 다른 결과 |
| | 익숙한 칠성사이다가 / 낯선 공간을 만났을 때 | 익숙함 × 낯섦 |
| 작은 것의 큰 효과 | 골퍼들의 발길을 붙잡은 / 한 뼘짜리 포토존 | 작은 장치 하나가 핵심 |
| 타깃 호명 | 첫 팬을 만드는 게 고민인 / 뷰티 브랜드에게 | 독자(브랜드 담당자)의 고민을 직접 부름 |

기본 재료: **"그 업종에서 보통 하는 것과 다른 행동"**.

## 2. 본문 6단계 공식

| 단계 | 역할 | 자주 쓰는 표현 |
|---|---|---|
| ① 상황 설정 (2장) | 시기·장소·브랜드 | "지난 X월, [장소]에서 [브랜드]의 팝업이 열렸어요." + "그런데" |
| ② 통념 제시 | 보통은 이렇게 한다 | "보통 ~는 ~에 집중합니다", "대체로 비슷한 구성으로 운영되는데요" |
| ③ 반전 공개 | 핵심 장치 등장 | "바로 ~입니다", "진짜 차별점은 ~에 숨어 있었습니다" |
| ④ 질문 | 다음 장으로 넘기게 함 | "왜 이런 결정을 했을까요?", "과연 무엇일까요?" |
| ⑤ 의도 해석 | 브랜드 전략 관점 풀이 | "~했던 거예요", "~한 거죠" |
| ⑥ 일반화 + 독자 질문 (마지막 장) | 사례를 교훈으로 확장, 독자에게 돌려줌 | "~는 건 어떨까요?", "여기부터 고민을 시작해 보세요" |

②와 ③의 순서는 바뀌어도 된다. 마지막 장 다음에는 항상 **스위트스팟 소개 장**이 붙는다(문구는 고정, 본문 작성 대상 아님).

### 필수 장치

- **"A가 아니라 B" 구조**를 반드시 한 번 쓴다. 이것이 스위트스팟의 시그니처다.
  - 말로 전하는 메시지 → 몸으로 겪는 경험 (룰루레몬)
  - 책상 → 그 위에서 펼쳐지는 삶 (오프레임)
  - 맛있는 커피 → 편리한 사용성에 대한 납득 (필립스)
  - 화려한 기술 → 고객의 감정 이해 (캘러웨이)
  - 완성된 결과물 → 만들어지는 과정 (블룸타이드)
  - 같은 공간 → 브랜드 맥락으로 재해석 (알맹이·탐스)
  - 익숙함에 머무르기 → 해마다 새로운 경험 더하기 (칠성사이다)
- 결론은 항상 **"제품 판매가 아니라 경험 설계"** 관점으로 모인다.
- **장 사이에서 문장 끊기**(예: "~핵심이었기" → 다음 장 "때문에")는 넘김을 유도한다. 한 콘텐츠에 1~2번까지만.
- 마지막 장은 독자에게 질문을 던지고 끝낸다. 가능하면 소개 장으로 이어지는 **다리 문장** 한 줄을 더한다 (예: "그 고민, 스위트스팟이 함께합니다").

### 추가 권장 (전환력 개선)

- **제작 비하인드 장 1장**: 스태프 배치, 재료 관리, 대기 동선처럼 만든 사람만 아는 운영 디테일. 필립스 6장이 모범 사례.
- **성과 한 줄**: 방문객 수, 대기, 판매, SNS 인증 수. 공개 불가 시 "오픈 첫날 오전 대기 마감" 같은 정성적 성과.
- 제공된 정보에 없는 성과·수치·역할은 지어내지 않는다. 필요하면 `[수치 확인 필요]`로 비워둔다.

## 3. 문체와 톤

- **존댓말 두 가지 혼용**: "~입니다/~습니다"(설명) + "~했어요/~거든요/~죠/~인데요"(대화). 전문가가 옆에서 설명하는 느낌.
- **관찰자 시점**: 본문에서 "우리가 만들었다"고 말하지 않는다. 업계 사례를 분석하는 에디터처럼 쓴다. (제작 비하인드 장도 "~했습니다" 관찰형으로)
- 연결어: 바로, 그런데, 특히, 결국, 이처럼
- 핵심어: 경험, 설계, 기억, 감정, 삶의 방식, 본질, 디테일, 과정
- 분량: 전체 7~8장(+소개 장), 장당 3~5문장, 약 150~250자. 텍스트형 카드뉴스.
- 시점 표현은 구체적으로: "작년 이맘때"보다 "2025년 가을".

## 4. 캡션 공식

```
📌 [1장 제목을 바꿔 쓴 한 줄 또는 질문]

[시기·장소·브랜드 요약 1~2문장]. [흥미 포인트 한 문장]인데요. [질문]? 피드를 통해 확인해보세요! >

.

[브랜드]에 대한 더 자세한 이야기는 스위트스팟 포트폴리오에서 확인하실 수 있습니다.

브랜드를 위한 오프라인 경험 제작사 | 스위트스팟 @sweetspot_official
```

- 캡션은 본문 요약이 아니다. **궁금증만 한 번 더 자극하고 답은 주지 않는다.**
- 표기 통일: `📌 ` 뒤 한 칸 띄움, "더 자세한"(더욱 X), 서명은 `브랜드를 위한 오프라인 경험 제작사 | 스위트스팟 @sweetspot_official`.
- 전환 강화 옵션 (사용자가 원할 때): 포트폴리오 위치 명시("프로필 링크에서"), 문의 경로 한 줄("팝업 기획 문의는 DM 또는 프로필 링크로").

## 5. 검수 체크리스트

- [ ] 1장에 답이 드러나지 않는가
- [ ] 본문과 캡션의 날짜·장소·체험 명칭·브랜드 설명이 일치하는가 (캘러웨이 사례: 본문 3월/캡션 4월, 퍼팅 챔피언십/챌린지 불일치가 있었음)
- [ ] "A가 아니라 B" 구조가 있는가
- [ ] 마지막 장이 독자에게 질문을 돌려주는가
- [ ] 자주 틀리는 띄어쓰기: "만드는 게", "전달했을까요/제공했을까요"(붙여 씀), "'제로'까지"(붙여 씀), 마침표 뒤 띄어쓰기
- [ ] 캡션 서명 형식이 정확한가
- [ ] 지어낸 사실·수치가 없는가
