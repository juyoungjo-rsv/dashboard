# 스위트스팟 인스타그램 포트폴리오 콘텐츠 작성 가이드

- 계정: @sweetspot_official (브랜드를 위한 오프라인 경험 제작사)
- 콘텐츠 유형: 오프라인 경험(팝업·부스·캠페인) 사례를 분석하는 **인사이트 카드뉴스**
- 기준 자료: 성과가 좋았던 콘텐츠 7개 + 사용자가 직접 다듬은 YES24 최종본 (`EXAMPLES.md`)

---

## ★ 가장 중요한 원칙: 홍보가 아니라 인사이트

이 콘텐츠는 **홍보용이 아니다.** 스위트스팟을 자랑하는 글이 아니라, 브랜드 담당자가 저장해두고 싶은 **업계 인사이트**로 읽혀야 한다.

스위트스팟은 **은근히만 드러난다.**

> 독자의 흐름: "인사이트 좋네" → "근데 이렇게 잘한 걸 누가 만든 거지?" → (소개 장·캡션을 보고) "스위트스팟이구나"

그래서 본문에서는 하지 않는다.

- "스위트스팟이 기획했다", "우리가 만들었다" 같은 제작 주체 언급
- 스위트스팟이 잘했다는 근거를 보여주려고 운영·제작 비하인드를 끼워 넣기
- 소개 장으로 이어지는 "그 고민, 스위트스팟이 함께합니다" 같은 다리 문장
- 문의·DM·링크를 요청하는 행동 유도 문구

스위트스팟이 드러나는 곳은 **본문 뒤 소개 장**과 **캡션 마지막 두 줄(포트폴리오 안내, 서명)**뿐이다.
운영·제작 디테일은 그 자체가 핵심 인사이트일 때만 쓴다(예: 필립스 6장).

---

## ★ 두 번째 원칙: 정보는 과감하게 뺀다

- 콘텐츠 하나에 **메시지는 하나.** 그 메시지를 받쳐주지 않는 정보는 사실이어도 뺀다.
- 수치, 굿즈, 부가 프로그램, 캠페인 세부 규칙은 "이게 없으면 메시지가 약해지나?"를 기준으로 판단한다. 아니면 뺀다.
- 자료가 많을수록 더 많이 버린다. 정보가 많아 보이면 실패다.
- YES24 사례: 시즌1 참여 수치, 10분=1km 환산 기준, NFC 메달 키링, 체험 구역 분리 운영을 모두 뺐고 더 좋아졌다.

## 0. 작성 요청을 받으면

### 받을 정보 (없는 항목은 비워두고 진행, 모르는 사실은 지어내지 않는다)

| 항목 | 예시 |
|---|---|
| 브랜드 / 제품·캠페인 | YES24 / 리딩런 캠페인 |
| 시기·장소 | 2026년 6월, 코엑스 서울국제도서전 |
| 목적·과제 | 앱 캠페인을 오프라인에서 전달 |
| 핵심 장치 | 소리 내어 읽으면 AI가 글자 수를 거리로 환산 |
| 기타 구성 | 하이드레이션 존, 피날레 월 등 |
| 참고 자료 | 포트폴리오 설명, 기사 링크 |

자료가 포트폴리오 페이지와 기사로 나뉘어 있으면 명칭·내용이 서로 다른지 확인하고 알린다.

### 결과물 형식

1. 1장 표지 제목 후보 3개 (유형별로 다르게) + 추천 1개
2. 본문 (장 번호 표기, 6~7장, 장당 3~5문장, 약 150~250자)
3. 캡션 (아래 캡션 공식 그대로)
4. 확인이 필요한 사실 목록 (날짜·명칭·수치 등 추측한 부분)

## 1. 표지 제목 (훅)

2줄 구성. 첫 줄이 긴장을 만들고 둘째 줄이 대상을 밝힌다. **답은 표지에 절대 넣지 않는다.** 가능하면 브랜드명을 넣는다.

| 유형 | 예시 | 원리 |
|---|---|---|
| 역설 + 이유 | 룰루레몬은 왜 잠실에 / 사우나를 열었나 | 브랜드와 어울리지 않는 행동, 이유는 숨김 |
| | 가구 브랜드가 / 제품 대신 '방'을 판 이유 | 업종 상식을 뒤집음 |
| | 고객을 번거롭게 만든 / 필립스의 숨은 전략 | 부정어가 긍정적 전략으로 |
| 대비 | 같은 장소, 같은 컨셉인데 / 결과는 달랐다 | 같은 조건, 다른 결과 |
| | 익숙한 칠성사이다가 / 낯선 공간을 만났을 때 | 익숙함 × 낯섦 |
| 작은 것의 큰 효과 | 골퍼들의 발길을 붙잡은 / 한 뼘짜리 포토존 | 작은 장치 하나가 핵심 |
| 타깃 호명 | 첫 팬을 만드는 게 고민인 / 뷰티 브랜드에게 | 독자(브랜드 담당자)의 고민을 직접 부름 |

기본 재료: **"그 업종에서 보통 하는 것과 다른 행동"**.

## 2. 본문 공식

| 단계 | 역할 | 자주 쓰는 표현 |
|---|---|---|
| ① 상황 + 궁금증 (첫 장) | 시기·장소·브랜드, 공간의 모습을 묘사하고 질문으로 끝냄 | "지난 X월, ~가 열렸어요. 유독 눈길을 끄는 공간이 있었는데요. 바로 ~입니다." / "~에 웬 ~일까요?" |
| ② 배경 | 브랜드가 이 경험을 만든 이유(캠페인·과제) | "~의 배경에는 ~이 있습니다" |
| ③ 핵심 장치 | 체험을 구체적으로 | "그렇다면 ~을 어떻게 구현했을까요?" |
| ④ 의도 해석 | 왜 이렇게 설계했는지 | "~는 ~를 그대로 복제하지 않았습니다", "~한 것이죠" |
| ⑤ 디테일 | 콘셉트를 완성한 공간 요소 (메시지에 필요한 것만) | "~의 디테일까지 공간 곳곳에 녹여져 있었는데요" |
| ⑥ 결론 | 사례를 브랜드 담당자가 쓸 수 있는 교훈으로 | 질문형("~는 건 어떨까요?") 또는 선언형("~ 그것이 ~의 핵심입니다") |

- 통념("보통 ~는 ~합니다")은 별도 장으로 두지 않아도 된다. 첫 장 질문에 녹일 수 있다 ("책이 빼곡해야 할 것 같은 도서전에 웬 러닝 트랙일까요?").
- 마지막 장 다음에는 항상 **스위트스팟 소개 장**이 붙는다(문구 고정, 작성 대상 아님).

### 인사이트는 "브랜드 담당자가 자기 일에 가져갈 수 있는 것"이어야 한다

- 좋은 인사이트: **"온라인 캠페인을 오프라인으로 옮길 때, 그대로 복제하지 말고 현장에 맞게 다시 설계하라"** (YES24). 같은 고민을 하는 마케터가 바로 적용할 수 있다.
- 약한 인사이트: "독서는 티가 안 나서 기록을 입혔다". 사실이지만 소재(독서)에 대한 이야기라 독자의 업무와 한 단계 떨어져 있다.
- 소재에 대한 감상보다 **설계 방법**에 대한 통찰을 우선한다.

### 필수 장치

- **"A가 아니라 B" 구조**를 한 번 쓴다.
  - 말로 전하는 메시지 → 몸으로 겪는 경험 (룰루레몬)
  - 책상 → 그 위에서 펼쳐지는 삶 (오프레임)
  - 맛있는 커피 → 편리한 사용성에 대한 납득 (필립스)
  - 화려한 기술 → 고객의 감정 이해 (캘러웨이)
  - 완성된 결과물 → 만들어지는 과정 (블룸타이드)
  - 같은 공간 → 브랜드 맥락으로 재해석 (알맹이·탐스)
  - 익숙함에 머무르기 → 해마다 새로운 경험 더하기 (칠성사이다)
  - 앱 경험 복제 → 현장에 맞춰 참여·기록·완주하는 경험으로 재구성 (YES24)
- 결론은 **"제품·메시지 전달이 아니라 경험 설계"** 관점으로 모인다.
- **장 사이에서 문장 끊기**는 넘김을 유도한다. 한 콘텐츠에 1~2번까지만.
- 제공된 정보에 없는 성과·수치는 지어내지 않는다.

## 3. 문체와 톤

- **존댓말 두 가지 혼용**: "~입니다/~습니다"(설명) + "~했어요/~인데요/~죠"(대화). 전문가가 옆에서 설명하는 느낌.
- **관찰자 시점**: 업계 사례를 분석하는 에디터처럼 쓴다. 제작 주체는 언급하지 않는다.
- 연결어: 바로, 그런데, 그렇다면, 특히, 결국, 이처럼
- 핵심어: 경험, 설계, 기억, 감정, 본질, 디테일, 과정, 재구성
- 분량: 본문 6~7장(+표지, +소개 장), 장당 3~5문장, 약 150~250자.
- 한 문장에 쉼표로 3개 이상 이어 붙이지 않는다. 길면 둘로 나눈다.
- 병렬 문장은 구조를 맞춘다 ("중간에는 ~이, 결승선에는 ~이").
- 시점 표현은 구체적으로: "작년 이맘때"보다 "2025년 가을".
- 브랜드 표기는 공식 표기 그대로 (YES24, 대문자).

## 4. 캡션 공식

```
📌 [표지 제목을 바꿔 쓴 한 줄 또는 질문]

[시기·장소·브랜드 요약 1~2문장]. [흥미 포인트 한 문장]인데요. [질문]? 피드를 통해 확인해보세요! >

.

[브랜드]에 대한 더 자세한 이야기는 스위트스팟 포트폴리오에서 확인하실 수 있습니다.

브랜드를 위한 오프라인 경험 제작사 | 스위트스팟 @sweetspot_official
```

- 캡션은 본문 요약이 아니다. **궁금증만 한 번 더 자극하고 답은 주지 않는다.**
- 스위트스팟은 마지막 두 줄에서만 드러난다. 문의 유도 문구는 넣지 않는다.
- 표기 통일: `📌 ` 뒤 한 칸 띄움, "더 자세한"(더욱 X), 서명 형식 고정.

## 5. 검수 체크리스트

- [ ] 홍보처럼 읽히는 문장이 없는가 (제작 주체 언급, 다리 문장, 행동 유도)
- [ ] 메시지가 하나인가, 빼도 되는 정보가 남아 있지 않은가
- [ ] 인사이트가 브랜드 담당자의 업무에 적용 가능한가
- [ ] 표지에 답이 드러나지 않는가
- [ ] 본문·캡션·포트폴리오·기사의 날짜·장소·프로그램 명칭이 일치하는가
- [ ] "A가 아니라 B" 구조가 있는가
- [ ] 자주 틀리는 띄어쓰기: "만드는 게", "전달했을까요/제공했을까요"(붙여 씀), "'제로'까지"(붙여 씀), 마침표 뒤 띄어쓰기
- [ ] 브랜드 공식 표기, 캡션 서명 형식이 정확한가
- [ ] 지어낸 사실·수치가 없는가
